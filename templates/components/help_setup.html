Set up the parts you want to use. You can reopen this guide from Help at any time.

1 · Connect your sources

CivitAI offers limited discovery before connecting. Connect CivitAI Red and SeaArt to include them in scans. Check Source Accounts for connection status and available authentication options.

2 · Choose how to download

Local Installer (recommended) saves each model to your ComfyUI folder or a custom model folder and links it to your Downloaded library automatically. You can track progress, open the saved folder, and start reviewing and tagging as soon as the download finishes.

Browser downloads save through your browser. To track one in your library, choose Library maintenance → Add existing model files.

3 · Review automatic retention

Choose how long discovered model cards stay in your feed. Review the normal-scan and creator/discovery windows and the protected-model rules before enabling cleanup.

4 · Make it yours

Adjust appearance and source colors in Library settings.

Your models, one file at a time

Completed Local Installer downloads and files you link appear here. Use Library maintenance → Add existing model files for models saved by your browser or downloaded elsewhere.

Find and organize

Search model names, filenames, creators, creator tags, and personal tags. Filter by source, architecture, type, review state, or favorites. Use the review dropdown to mark a file and select its tags to edit them.

Manage files

Open folder takes you to the saved location. File details shows the full path and recorded dates. Delete local file removes the selected file after confirmation. Past downloads retains history for files no longer tracked as installed.

Moved files? Use Update model locations. Find duplicate files compares full SHA-256 hashes to identify identical file contents, even when filenames differ.
