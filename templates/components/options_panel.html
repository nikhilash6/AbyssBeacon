Update LibraryApply newer AbyssBeacon metadata rules to existing cards ▾
When AbyssBeacon learns how to interpret existing source data differently, this updates saved library entries without running a broad source scan. Most entries use data already stored locally; older entries missing repository or version statistics are refreshed individually from their source. Future library metadata upgrades can use this same tool.
Large libraries may take several hours to update, especially older CivitAI/Red entries needing fresh version statistics. Keep AbyssBeacon running and prevent your computer from sleeping until completion. Successfully upgraded entries do not need the same upgrade again.
