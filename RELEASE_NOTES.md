# AbyssBeacon 2.0.0

Discover, identify, and organize your local models.

- Open the Downloaded library directly from the navbar. Search model and personal tags, filter by download source, and review individual files and versions.
- Install to ComfyUI or a custom model folder with the original filename. Track completed installs and open their recorded folders.
- Link existing models, locate moved files, and find duplicate copies by SHA-256. Browser downloads can be linked after saving.
- Browse large collections 100 families at a time. Search and sort across the entire collection. Collection favorite changes are reflected when returning to the feed.
- Use the first-time setup and library guides from Help, including shortcuts to download, retention, and appearance settings.
- Public TensorHub Art creator exclusions remain enabled for names and stable owner IDs.


- Identify sign-in-required CivitAI versions through lightweight, cached version checks; keep paid and restricted access labels distinct.
- Reject sign-in HTML and incomplete SafeTensors transfers instead of marking them successfully installed.
- Manage duplicate copies directly from Find Duplicate Files, using explicit confirmation, SHA-256 checks, and Windows Recycle Bin; automatically refresh affected results.
- Add improved compact architecture variant selectors and first-run v2 setup guides for new and upgrading users.
- Update the project README with illustrated discovery, downloading, import, library, and Firefox companion documentation.

For a new installation use the full Git source ZIP. For an existing v1.5.1 installation, close AbyssBeacon, back up its folder, and apply the upgrade ZIP over the directory containing app.py. Restart and hard-refresh.
